# 대한민국 천만 관객 한국 영화 흥행 분석 대시보드

위키백과의 [대한민국의 영화 흥행 기록](https://ko.wikipedia.org/wiki/대한민국의_영화_흥행_기록) 문서에서 천만 관객을 돌파한 한국 영화 데이터를 웹 스크래핑으로 수집하고, 정제 및 시각화하는 Streamlit 웹 애플리케이션입니다.

## 주요 기능

1. **웹 데이터 수집 (`fetch_html`)**
   - `requests` 라이브러리를 이용해 위키백과 HTML 문서를 요청합니다.
   - 교육 및 실습 목적임을 명시한 `User-Agent` 헤더와 10초 `timeout`을 적용했습니다.
   - 연결 실패, 시간 초과, HTTP 상태 오류 등에 대한 예외 처리를 포함합니다.

2. **표 파싱 및 변환 (`parse_movie_table`)**
   - `BeautifulSoup`을 사용하여 `class="wikitable"` 표 중 헤더에 `'관객수'`와 `'감독'`이 모두 포함된 첫 번째 표를 탐색합니다.
   - 불필요한 각주 번호(`<sup>` 태그)를 제거한 뒤 `pandas.DataFrame`으로 변환합니다.

3. **데이터 정제 (`clean_movie_data`)**
   - 영화 제목 양옆의 겹낫표(`《`, `》`)를 제거합니다.
   - 문자열 형태의 관객수 데이터에서 숫자만 추출하여 정수형(`int`)으로 변환합니다.
   - 개봉일 데이터에서 정규표현식을 활용해 `개봉연도`와 `개봉월` 파생 변수를 생성합니다.

4. **데이터 시각화 및 대시보드 (`display_dashboard`, `plot_distributor_pie`)**
   - **핵심 지표(KPI):** 총 천만 영화 편수, 역대 1위 영화 제목, 1위 관객수를 상단에 요약 표시합니다.
   - **데이터 테이블:** 인덱스를 숨긴 깔끔한 표 형태로 전체 목록을 제공합니다.
   - **차트 분석:**
     - 관객수 상위 10편 가로 막대 차트
     - 개봉 연도별 편수 막대 차트
     - 한국내 주요 배급사별(상위 4개사 및 기타) 점유율 원그래프 (OS별 한글 폰트 자동 설정 포함)

## 요구 사항 (Requirements)

이 프로젝트를 실행하려면 Python 3.8 이상과 아래의 라이브러리가 필요합니다.

```bash
pip install streamlit requests beautifulsoup4 pandas matplotlib
```

*참고: Linux 환경에서 실행할 경우 원그래프의 한글 깨짐 방지를 위해 나눔고딕(`fonts-nanum`) 설치가 필요할 수 있습니다.*

## 실행 방법

1. 소스 코드가 저장된 디렉터리로 이동합니다. (예: `app.py`)
2. 터미널에서 아래 명령어를 입력해 Streamlit 서버를 실행합니다.

```bash
streamlit run app.py
```

3. 브라우저가 자동으로 열리면 화면의 **데이터 수집 및 분석 시작** 버튼을 클릭하여 결과를 확인합니다.
